# Master Goal for OpenCode 2

Master Goal keeps a goal active until its locked verification contract passes. Model claims of completion cannot satisfy the contract.

## Highlights

- OpenCode 2.x native server plugin, `/goal` command, and sidebar integration.
- Natural-language workflow: `/goal init`, edit `goal.md`, `/goal construct`, then `/goal start`.
- Deterministic equality, file, and local-script checks with pinned verifier integrity. Optional review can veto success.
- Explicit forever mode with no success transition or default iteration budget.
- Persistent goal state and context reinjection across compaction.
- Goal token totals, cost, iterations, verification progress, and todos. Throughput display is left to OpenCode 2.
- Global and project-local installers with durable runtime registration, Windows path handling, and atomic state-file retries.

## Install

Requires OpenCode 2.x and Node.js 22 or newer. Close OpenCode first.

```powershell
npx --yes --package=github:darkmatter2222/opencode_mastergoal#v0.3.0 mastergoal install --global
opencode service stop
opencode
```

For a project-local install, replace `--global` with `--local` from the project directory. In OpenCode, run `/goal help`.

## Validation and limits

The release commit passed all eight CI jobs, including Windows/macOS/Linux tests, real OpenCode 2 integration, sidebar rendering, and Windows packaged installation. The suite includes 108 tests and 20 deterministic goal scenarios; these are not an LLM success-rate benchmark.

Model-generated verification still requires review for semantic adequacy. Host shutdown, provider failures, permission waits, and explicit stop/pause can interrupt a goal without marking it complete. OpenCode 1.x is not supported.

The attached npm tarball contains the compiled runtime. SHA256SUMS covers that artifact. This is a GitHub release; it does not publish the package to the npm registry.
