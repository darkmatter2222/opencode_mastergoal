# Plain Markdown forever loops

`/goal forever my-prompt.md` now repeats an ordinary Markdown prompt directly. No init, construction, compiled contract, or verifier is required.

- Saves the prompt and sends its exact contents after each completed model turn, without overlapping requests.
- Completion claims and completed todos do not end the loop.
- Embedded contract fences are task text; their verifiers and budgets are not executed.
- Pause, resume, stop, end, persisted recovery, and session accounting remain supported.
- Finite `/goal start` goals retain deterministic completion checks. Existing contract-based forever runs retain health-check behavior.
- Source edits take effect after stop/start. Resume the saved run after restarting OpenCode.

## Update

Close OpenCode, then run:

```powershell
opencode service stop
npx --yes --package=github:darkmatter2222/opencode_mastergoal#v0.4.1 mastergoal install --global
opencode
```

Use `--local` instead of `--global` for a project installation. Then run `/goal forever my-prompt.md` inside OpenCode.
